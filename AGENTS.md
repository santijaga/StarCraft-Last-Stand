# Правила проекта

Проект — клон Crimsonland в стиле StarCraft на Unity.

## Журнал разработки

- Журнал разработки: [devlog.md](devlog.md) в корне проекта. Перед началом работы читать его для понимания уже реализованных механик и текущего состояния проекта.
- После каждой реализации, исправления или изменения настроек обновлять журнал в рамках той же задачи.
- Записывать дату, что изменено, затронутые скрипты/сцены/ресурсы и результат для игрока. Сохранять предыдущие записи.
- Отдельно указывать статус ручной проверки и известные ограничения. Не отмечать функциональность проверенной без фактического подтверждения.

## Тестирование

- Не писать и не добавлять автоматические тесты.
- Использовать только ручное тестирование. Проверку игрового поведения в Unity выполняет пользователь.
- Не запускать автоматические тесты и не создавать для них инфраструктуру или временные копии проекта.
- При передаче изменений кратко описывать, что пользователю проверить вручную.
